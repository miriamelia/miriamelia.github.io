# miriamelia.github.io

Personal website of Miriam Elia, PhD — Responsible AI · Lifecycle Design · Evaluation.

Live at https://miriamelia.github.io

## Stack

Plain HTML and CSS, served by GitHub Pages from `main`. No build step.
To preview locally, open `index.html` in a browser (double-click).

## Files

- `index.html` — homepage (single-page scroll)
- `cv.html` — full CV web view (also rendered to PDF via print stylesheet)
- `assets/style.css` — site styles
- `assets/print.css` — print stylesheet for CV → PDF
- `assets/profile.jpg` — portrait
- `assets/cv.pdf` — generated CV (linked from the site)
- `.nojekyll` — disables Jekyll processing on GitHub Pages
